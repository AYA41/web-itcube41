Таблицы: <table>, <tr>, <td> и <th>

Таблицы помогают упорядочить данные в виде строк и столбцов, как в школьном расписании, таблице умножения или прайс-листе. Давай разберёмся, как их создавать!

🏗️ Базовая структура таблицы

Представь таблицу как конструктор. Чтобы её собрать, нам нужно три основных элемента:

  • <table> — общая «коробка», которая говорит браузеру: «Здесь начинается таблица».
  • <tr> (Table Row) — строка таблицы.
  • <td> (Table Data) — ячейка с данными внутри строки.
HTML Простая таблица 2x2 
<table>
  <tr>
    <td>Ячейка 1 (строка 1, столбец 1)</td>
    <td>Ячейка 2 (строка 1, столбец 2)</td>
  </tr>
  <tr>
    <td>Ячейка 3 (строка 2, столбец 1)</td>
    <td>Ячейка 4 (строка 2, столбец 2)</td>
  </tr>
</table>

👑 Заголовки таблиц: <th>

Обычные ячейки <td> хороши для данных, но для заголовков столбцов или строк лучше использовать тег <th> (Table Header). Браузер автоматически сделает текст внутри него жирным и выровняет по центру, а программы для чтения с экрана поймут, что это заголовок. 

<table>
  <tr>
    <th>Имя</th>
    <th>Возраст</th>
    <th>Город</th>
  </tr>
  <tr>
    <td>Аня</td>
    <td>12</td>
    <td>Петропавловск-Камчатский</td>
  </tr>
</table>

🧩 Семантические части таблицы

Если таблица большая, её принято делить на три логические части. Это не меняет внешний вид, но делает код профессиональным и понятным:

  • <thead> (Table Head) — «голова» таблицы. Здесь живут строки с заголовками <th>.
  • <tbody> (Table Body) — «тело» таблицы. Здесь находятся основные данные <td>.
  • <tfoot> (Table Foot) — «подвал» таблицы. Используется для итогов (например, «Всего: 1000₽»). Важно: в коде <tfoot> часто пишут до <tbody>, чтобы браузер загрузил итоги раньше!

🔮 Магия объединения: colspan и rowspan

Иногда нужно, чтобы одна ячейка занимала место двух или более соседних. Для этого есть два волшебных атрибута: 

<table>
  <tr>
    <!-- Эта ячейка растянется на 2 столбца -->
    <th colspan="2">Общий заголовок</th>
  </tr>
  <tr>
    <td>Ячейка 1</td>
    <td>Ячейка 2</td>
  </tr>
</table>
  • colspan="N" — объединяет N столбцов (работает горизонтально).
  • rowspan="N" — объединяет N строк (работает вертикально).
⚠️
Важно про внешний вид: По умолчанию HTML-таблицы выглядят как просто текст, слепленный вместе, без видимых границ. Чтобы добавить сетку, отступы и цвета, мы будем использовать CSS (тема border, padding и border-collapse). Не пугайся, если пока таблица выглядит «скучно» — это нормально!

🚀 Практическое задание: «Расписание экспедиции»

Создай файл schedule.html и составь план похода на вулкан:

  1. Создай таблицу <table>.
  2. Используй <thead> и <th> для заголовков столбцов: «Время», «Мероприятие», «Снаряжение».
  3. Используй <tbody> для добавления минимум 3 строк <tr> с данными <td> (например, "08:00", "Сбор у подножия", "Рюкзаки, вода").
  4. Попробуй добавить итоговую строку в <tfoot> и объедини ячейки с помощью colspan="2" для текста «Итого: 1 день в пути».
  5. Сохрани и открой в браузере. Да, пока это просто текст, но структура идеальна! В следующем модуле мы научимся делать из этого красивую сетку с помощью CSS.
