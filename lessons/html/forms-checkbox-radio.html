Флажки и переключатели: checkbox и radio

Что делать, если нужно дать пользователю выбор? Если вариантов много и можно выбрать несколько — используем флажки. Если выбрать можно только один — используем переключатели.

✅ Флажок (Checkbox): «Выбери всё, что нравится»

Тег <input type="checkbox"> создаёт маленький квадратик. Пользователь может отметить ноль, один или несколько вариантов сразу.

Аналогия: Список вещей в рюкзак. Ты можешь взять и фонарик, и бутерброд, и фотоаппарат одновременно.

HTML Пример чекбоксов 
<p>Что возьмём в поход?</p>

<input type="checkbox" id="item1" name="gear" value="flashlight">
<label for="item1">Фонарик</label><br>

<input type="checkbox" id="item2" name="gear" value="camera" checked>
<label for="item2">Фотоаппарат (уже отмечено!)</label>
💡
Зачем нужен атрибут value?
Текст внутри <label> видит человек. А значение атрибута value увидит компьютер (сервер), когда форма будет отправлена. Именно value передаёт данные!

📻 Переключатель (Radio): «Выбери только один»

Тег <input type="radio"> создаёт круглую кнопку. Из группы таких кнопок пользователь может выбрать строго одну. Если нажать на другую, предыдущая автоматически отключится.

Аналогия: Кнопки на старом автомобильном радио. Когда ты вдавливаешь одну, все остальные выскакивают. 

<p>Как доберёмся до вулкана?</p>

<input type="radio" id="transport1" name="transport" value="bus">
<label for="transport1">На автобусе</label><br>

<input type="radio" id="transport2" name="transport" value="heli">
<label for="transport2">На вертолёте</label><br>

<input type="radio" id="transport3" name="transport" value="foot" checked>
<label for="transport3">Пешком (уже отмечено!)</label>
⚠️
САМОЕ ГЛАВНОЕ ПРАВИЛО:
Чтобы переключатели работали как группа (отключались при выборе другого), у них должен быть одинаковый атрибут name! В примере выше у всех трёх вариантов name="transport". Если имена будут разными, можно будет выбрать все варианты сразу, и магия сломается.

🔑 Атрибут checked

Если ты хочешь, чтобы при загрузке страницы какой-то вариант уже был выбран по умолчанию (например, самый популярный), просто добавь слово checked внутрь тега <input>. Ему не нужно значение, он работает как переключатель «вкл/выкл».

🚀 Практическое задание: «Анкета туриста»

Создай файл tourist-anketa.html и добавь в него форму с выбором:

  1. Создай группу переключателей (radio) с вопросом «Твой уровень подготовки:». Варианты: «Новичок», «Любитель», «Профи». У всех должен быть одинаковый name, но разные id и value.
  2. Создай группу флажков (checkbox) с вопросом «Что ты любишь фотографировать?». Варианты: «Вулканы», «Медведи», «Океан», «Северное сияние». Здесь name тоже может быть одинаковым (например, name="photo_interest").
  3. Сделай так, чтобы вариант «Новичок» и вариант «Вулканы» были отмечены по умолчанию с помощью атрибута checked.
  4. Не забудь обернуть каждый вариант в правильную пару <input> + <label> с атрибутами for и id!
