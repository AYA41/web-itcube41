Гиперссылки: тег <a> и атрибут href

Ссылки — это «порталы» интернета. Они позволяют пользователю одним кликом переместиться на другую страницу твоего сайта, на чужой сайт или даже начать писать письмо.

⚓ Основа всего: тег <a>

Буква a расшифровывается как anchor (якорь). Но чтобы якорь зацепился за нужное место, ему обязательно нужен атрибут href (Hypertext Reference — ссылка на ресурс).

HTML Базовая ссылка 
<a href="https://yandex.ru">Перейти в Яндекс</a>

Всё, что находится между открывающим <a> и закрывающим </a>, становится кликабельным. Это может быть текст, картинка или даже целый блок!

🗺️ Два вида путей (Абсолютный и Относительный)

Это самая важная часть! Путь в href можно указать двумя способами:

<!-- 1. Абсолютный путь (полный адрес из интернета) -->
<!-- Используем для перехода на ДРУГИЕ сайты -->
<a href="https://kamchatka.travel">Путешествие по Камчатке</a>

<!-- 2. Относительный путь (путь внутри твоего проекта) -->
<!-- Используем для перехода между СВОИМИ страницами -->
<a href="about.html">О нас</a>
<a href="pages/contacts.html">Контакты (в папке pages)</a>
💡
Золотое правило: Если ссылка ведёт на чужой сайт, всегда пиши полный адрес с https://. Если ссылка ведёт на твой файл, пиши только его имя (и папку, если он в папке).

🪟 Открытие в новой вкладке: target

По умолчанию ссылка открывается в той же вкладке, и пользователь уходит с твоего сайта. Чтобы он остался у тебя, но смог посмотреть чужой ресурс, используй атрибут target="_blank". 

<a href="https://youtube.com" target="_blank" rel="noopener">
  Смотреть видео (откроется в новой вкладке)
</a>

Примечание: атрибут rel="noopener" добавляется для безопасности, чтобы новая вкладка не могла управлять твоей страницей.

📧 Специальные ссылки: почта и телефон

HTML умеет не только открывать страницы, но и запускать программы на компьютере пользователя:

<!-- Открыть почтовую программу для написания письма -->
<a href="mailto:hello@it-kamchatka.ru">Написать нам</a>

<!-- Предложить позвонить (отлично работает на смартфонах) -->
<a href="tel:+79991234567">Позвонить в IT-куб</a>

🖼️ Ссылка-картинка

Помнишь, мы говорили, что внутри <a> может быть что угодно? Вот как сделать кликабельную картинку:

<a href="https://google.com">
  <img src="logo.png" alt="Кликни на логотип">
</a>

🚀 Практическое задание: «Полезные ресурсы»

Создай файл resources.html и собери в нём коллекцию ссылок:

  1. Добавь заголовок <h1> «Полезные ссылки для программиста».
  2. Сделай ссылку на внешний сайт (например, https://html5book.ru или https://code.mu), которая открывается в новой вкладке.
  3. Сделай относительную ссылку, которая ведёт обратно на твою главную страницу index.html (текст ссылки: «Вернуться на главную»).
  4. Добавь ссылку mailto: с выдуманным адресом (например, mailto:coder@kamchatka.ru).
  5. Найди в интернете маленькую иконку или картинку, сохрани её и сделай так, чтобы при клике на неё открывался сайт https://yandex.ru.
