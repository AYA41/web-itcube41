Урок 08

Список определений: <dl>, <dt> и <dd>

В прошлом уроке мы мельком упоминали этот тег. Теперь давай разберём его подробно! Это лучший способ создать на сайте словарь, глоссарий или карточку с характеристиками.

📖 Из чего состоит список определений?

В отличие от обычных списков, здесь нет маркеров или цифр. Вместо этого есть чёткая структура «Термин — Описание». Для этого используются три тега:

  • <dl> (Definition List) — общая «обёртка» для всего списка.
  • <dt> (Definition Term) — сам термин или заголовок (то, что мы объясняем).
  • <dd> (Definition Description) — описание или расшифровка термина.
HTML Словарь юного программиста 
<dl>
  <dt>HTML</dt>
  <dd>Язык гипертекстовой разметки. Отвечает за структуру страницы.</dd>

  <dt>Браузер</dt>
  <dd>Программа, которая читает HTML-код и показывает нам красивый сайт.</dd>
</dl>
📏
Бонус от браузера: По умолчанию браузер автоматически добавляет небольшой отступ слева для тега <dd>. Это делает текст похожим на настоящий словарный артикул, и тебе даже не нужно подключать CSS!

🎯 Одно слово — несколько описаний

Иногда один термин можно объяснить по-разному или дать несколько характеристик. Хорошая новость: к одному <dt> можно прикрепить несколько тегов <dd> подряд! 

<dl>
  <dt>Кальдера</dt>
  <dd>Обширная впадина вулканического происхождения.</dd>
  <dd>(Пример: Кальдера вулкана Узон на Камчатке)</dd>
</dl>

💡 Где это использовать на практике?

Списки определений идеально подходят для:

  • 📚 Глоссариев и словарей на сайте.
  • 🏷️ Карточек товаров (например: <dt>Вес, <dd>150 грамм).
  • 👤 Профилей пользователей (например: <dt>Имя, <dd>Иван; <dt>Город, <dd>Петропавловск-Камчатский).
  • ❓ Блоков «Вопрос — Ответ» (если не использовать <details>).
⚠️
Частая ошибка: Нельзя писать обычный текст или ставить теги вроде <p> напрямую внутри <dl>. Внутри <dl> могут находиться только пары <dt> и <dd> (или другие <dl> для вложенности).

🚀 Практическое задание: «Энциклопедия Камчатки»

Создай файл glossary.html и сделай свой мини-словарь:

  1. Добавь заголовок <h1> «Словарь исследователя Камчатки».
  2. Создай список <dl> минимум с 3 терминами (например: «Гейзер», «Тундра», «Лосось»).
  3. Для одного из терминов используй два тега <dd>: в первом дай научное определение, а во втором — интересный факт (можно использовать тег <i> для курсива).
  4. Попробуй добавить внутрь одного из описаний <dd> маленькую картинку <img> с относительным путём.
  5. Сохрани и открой в браузере. Обрати внимание, как аккуратно браузер выстроил отступы для описаний!
