Специальные поля ввода: email, tel, date, color и другие

HTML5 добавил нам целую коллекцию «умных» полей. Они не просто выглядят по-другому — браузер сам помогает пользователю: открывает календарь, показывает цветовую палитру или включает нужную клавиатуру на телефоне.

🔒 Секретный ввод: type="password"

Когда пользователь вводит пароль, его не должны видеть посторонние. Поле type="password" автоматически скрывает символы за звёздочками или точками. 

<label for="pass">Придумай пароль:</label>
<input type="password" id="pass" name="password">

📧 Электронная почта: type="email"

Поле для ввода email. Браузер сам проверит, что пользователь ввёл «собаку» (@) и домен. А на смартфоне откроется клавиатура с символом @ и точкой — не нужно их искать! 

<label for="mail">Твой email:</label>
<input type="email" id="mail" name="email" placeholder="name@example.com">
✨
Атрибут placeholder — это серая подсказка внутри пустого поля. Она исчезает, как только пользователь начинает печатать. Отличный способ показать пример правильного ввода!

📞 Телефон: type="tel"

На компьютере это обычное текстовое поле, а вот на смартфоне браузер сразу откроет цифровую клавиатуру. Очень удобно! 

<label for="phone">Телефон для связи:</label>
<input type="tel" id="phone" name="phone" placeholder="+7 (___) ___-__-__">

🔗 Адрес сайта: type="url"

Поле для ввода веб-адреса. Браузер проверит, что пользователь указал протокол (http:// или https://). 

<label for="site">Ссылка на твой сайт:</label>
<input type="url" id="site" name="website" placeholder="https://">

📅 Дата и время: type="date" и type="time"

Магия! Вместо того чтобы заставлять пользователя вводить дату вручную (и потом разбирать её в формате «дд.мм.гггг»), браузер покажет удобный календарь. 

<label for="date">Дата восхождения:</label>
<input type="date" id="date" name="date">

<label for="time">Время выхода:</label>
<input type="time" id="time" name="time">

Также есть type="datetime-local" — для выбора даты и времени одновременно.

⚠️
Формат даты в коде: Если ты хочешь задать дату по умолчанию через атрибут value, пиши её в формате ГГГГ-ММ-ДД. Например: value="2026-07-15".

🎨 Выбор цвета: type="color"

При клике на такое поле браузер откроет стандартную цветовую палитру. Значение передаётся в формате HEX (например, #ff6b6b). 

<label for="tent">Цвет твоей палатки:</label>
<input type="color" id="tent" name="color" value="#ff6b6b">

📋 Шпаргалка: все типы полей

Сохрани себе эту табличку — она пригодится в каждом проекте:

type Что делает Фишка браузера
text Обычный текст —
password Скрытый ввод Прячет символы
email Электронная почта Проверка @, спец. клавиатура
tel Телефон Цифровая клавиатура
url Веб-адрес Проверка http://
number Число Стрелочки +/-, min/max/step
date Дата Календарь
time Время Выбор часов и минут
color Цвет Цветовая палитра
range Ползунок Удобный выбор из диапазона

🚀 Практическое задание: «Бронирование тура на Камчатку»

Создай файл booking.html и собери форму бронирования, используя все новые типы полей:

  1. Поле email для связи с туристом (с placeholder).
  2. Поле tel для номера телефона.
  3. Поле password для создания пароля личного кабинета.
  4. Поле url для ссылки на Instagram туриста (чтобы посмотреть его фото).
  5. Поле date для выбора даты начала тура.
  6. Поле time для выбора времени встречи в аэропорту.
  7. Поле color для выбора цвета фирменной футболки группы (по умолчанию — оранжевый #ff7b00).
  8. Внизу — кнопка <button type="submit"> «Забронировать тур».
  9. Не забудь про <label> для каждого поля и правильные id и name!
