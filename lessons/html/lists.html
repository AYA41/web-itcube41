Списки: <ul>, <ol> и <li>

Списки есть везде: меню в ресторане, список покупок, шаги для прохождения квеста. В HTML мы можем создавать как маркированные (с точками), так и нумерованные списки.

• Маркированный список: <ul>

Тег <ul> (Unordered List — неупорядоченный список) создаёт список, где каждый пункт отмечен маркером (точкой, кружком или квадратиком). Порядок пунктов здесь не важен.

HTML Список снаряжения 
<ul>
  <li>Рюкзак</li>
  <li>Термос с чаем</li>
  <li>Фотоаппарат</li>
</ul>

1. Нумерованный список: <ol>

Тег <ol> (Ordered List — упорядоченный список) создаёт список, где каждый пункт пронумерован (1, 2, 3...). Используй его, когда важен порядок действий. 

<ol>
  <li>Открыть редактор кода</li>
  <li>Написать HTML-разметку</li>
  <li>Сохранить файл и открыть в браузере</li>
</ol>
🧩
Золотое правило: Тег <li> (List Item — элемент списка) всегда должен находиться внутри <ul> или <ol>. Нельзя использовать <li> сам по себе!

📁 Вложенные списки

Что, если внутри пункта списка нужно сделать ещё один список? Это называется вложенностью. Просто помести новый <ul> или <ol> внутрь тега <li>. 

<ul>
  <li>Языки программирования
    <ul>
      <li>HTML (разметка)</li>
      <li>CSS (стили)</li>
      <li>JavaScript (логика)</li>
    </ul>
  </li>
  <li>Графические редакторы</li>
</ul>
⚠️
Важно про отступы: Браузеру всё равно, как ты расставишь пробелы и переносы строк. Но для тебя и других программистов очень важно делать отступы (Tab), чтобы видеть вложенность. Код должен быть читаемым, как лесенка!

📖 Список описаний: <dl>

Иногда нужно создать список пар «Термин — Описание» (как в словаре). Для этого используется специальный тег <dl> (Description List). 

<dl>
  <dt>HTML</dt>
  <dd>Язык гипертекстовой разметки.</dd>

  <dt>Браузер</dt>
  <dd>Программа для просмотра веб-страниц.</dd>
</dl>

Здесь <dt> (Definition Term) — это сам термин, а <dd> (Definition Description) — его расшифровка.

🚀 Практическое задание: «Квест по Камчатке»

Создай файл quest.html и составь план путешествия:

  1. Используй <h1> для названия квеста (например, «Тайны вулканов»).
  2. Создай нумерованный список <ol> из 3-4 основных этапов путешествия.
  3. Внутри одного из этапов (внутри тега <li>) создай вложенный маркированный список <ul> с вещами, которые нужно взять с собой на этом этапе.
  4. Внизу добавь список описаний <dl> с двумя терминами, которые встретились в квесте (например, «Кальдера» и «Гейзер»).
  5. Сохрани файл, открой в браузере и проверь, что все отступы отображаются красиво!
