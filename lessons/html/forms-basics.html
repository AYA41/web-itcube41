Основы форм: поля, кнопки и метки

Формы — это способ, с помощью которого сайт «разговаривает» с пользователем. Регистрация, поиск, отправка сообщений — всё это работает благодаря формам. Давай научимся их создавать!

📝 Контейнер формы: <form>

Любая форма начинается с тега-обёртки <form>. Он как папка, в которую мы складываем все поля для ввода. У него есть два главных атрибута:

  • action — адрес (URL), куда будут отправлены данные (пока мы можем оставить его пустым action="" или поставить #).
  • method — способ отправки: GET (данные видны в адресной строке) или POST (данные скрыты, используется для паролей и важных данных).

🏷️ Метка и поле: <label> и <input>

Самое важное правило форм: у каждого поля ввода должна быть метка (подпись). Для этого используется тег <label>.

Чтобы связать метку с полем, используют «волшебную ниточку»: атрибут for у метки должен совпадать с атрибутом id у поля ввода.

HTML Связь label и input 
<label for="username">Ваше имя:</label>
<input type="text" id="username" name="username">
🖱️
Зачем это нужно?
1. Удобство: Если кликнуть по тексту в <label>, курсор автоматически прыгнет в связанное поле ввода!
2. Доступность: Программы для чтения с экрана озвучивают название поля благодаря этой связке.

🔢 Ввод чисел: type="number"

Если нам нужно, чтобы пользователь ввёл только цифры (например, возраст или количество рюкзаков), мы меняем тип поля на number. Можно даже ограничить диапазон! 

<label for="backpacks">Количество рюкзаков:</label>
<input type="number" id="backpacks" name="backpacks" min="1" max="10" step="1">
  • min и max — минимальное и максимальное значение.
  • step — шаг изменения (по умолчанию 1, но можно сделать 0.5 или 10).

🚀 Кнопки и автофокус

Чтобы отправить форму, нужна кнопка. А чтобы сделать сайт чуть-чуть «умнее», можно использовать автофокус.

<!-- Автофокус сразу ставит курсор в это поле при загрузке страницы -->
<input type="text" id="name" autofocus>

<!-- Кнопка отправки формы -->
<button type="submit">Отправить заявку</button>

<!-- Обычная кнопка (пока ничего не делает, пригодится для JavaScript) -->
<button type="button">Просто кнопка</button>
⚠️
Важно: Не путай id и name в полях ввода.
id — нужен для связи с <label> и для CSS/JS (он уникален на странице).
name — это имя, под которым данные уйдут на сервер (как подпись на конверте).

🚀 Практическое задание: «Заявка на экспедицию»

Создай файл expedition-form.html и сделай простую форму регистрации:

  1. Создай тег <form> с атрибутом action="#".
  2. Добавь поле для ввода имени (type="text") с меткой <label>. Добавь атрибут autofocus, чтобы курсор сразу был там.
  3. Добавь поле для ввода возраста (type="number") с ограничением min="7" и max="99".
  4. Внизу добавь кнопку <button type="submit"> с текстом «Отправить заявку».
  5. Не забудь прописать уникальные id и name для каждого поля и связать их с for в метках!
