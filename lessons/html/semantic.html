Семантические теги: осмысленная разметка

До этого мы использовали <div> для всего. Это работает, но для браузера все блоки выглядят одинаково — как безликие коробки. Семантические теги говорят: «Это шапка, это меню, это статья, это подвал». Они добавляют смысл в разметку.

🏠 Аналогия с домом

Представь, что HTML-страница — это дом. Ты можешь построить его целиком из одинаковых бетонных блоков (<div>). Функционально всё будет работать, но гость не поймёт, где кухня, где спальня, а где гараж.

Семантические теги — это таблички на дверях. Они не меняют внешний вид, но сразу говорят: «Здесь вход», «Здесь лестница», «Здесь чердак».

🤖
Зачем это нужно?
1. Поисковикам (Яндекс, Google) — чтобы понимать структуру сайта и правильно его индексировать.
2. Программам чтения с экрана — незрячие пользователи могут быстро перейти к нужной части (например, сразу к <main>, минуя меню).
3. Тебе и команде — код становится читаемым, как хорошо написанная книга.

🏛️ «Скелет» страницы

Любая современная страница состоит из пяти основных частей:

🔝 <header> — шапка

Верхняя часть страницы или отдельного блока. Обычно содержит логотип, заголовок и главное меню.

<header>
  <img src="logo.svg" alt="IT-куб">
  <h1>IT-куб Камчатка</h1>
</header>

🧭 <nav> — навигация

Контейнер для меню. Внутри него обычно живут ссылки <a> или списки <ul>.

<nav>
  <ul>
    <li><a href="/">Главная</a></li>
    <li><a href="/html">HTML</a></li>
    <li><a href="/css">CSS</a></li>
  </ul>
</nav>

🎯 <main> — главное содержимое

Уникальный контент страницы. На всей странице может быть только один <main>. Сюда НЕ входят шапка, меню и подвал.

<main>
  <h1>Добро пожаловать!</h1>
  <p>Здесь основной контент страницы...</p>
</main>

📎 <aside> — побочное содержимое

Всё, что косвенно связано с основным контентом: боковая панель, реклама, список ссылок, блок «Читайте также».

<aside>
  <h3>Полезные ссылки</h3>
  <ul>
    <li><a href="#">Документация HTML</a></li>
  </ul>
</aside>

🔚 <footer> — подвал

Нижняя часть страницы. Обычно содержит копирайт, контакты, ссылки на соцсети.

<footer>
  <p>© 2026 IT-куб Камчатка</p>
</footer>

📰 Структура внутри <main>

А теперь самое интересное — как организовать контент внутри главной части.

📄 <article> — самостоятельная статья

Это независимый кусок контента, который имеет смысл сам по себе. Если его вырвать из страницы и отправить другу — он всё равно будет понятен.

Примеры: пост в блоге, новость, комментарий, карточка товара, виджет погоды.

<article>
  <h2>Извержение Ключевской Сопки</h2>
  <p>Сегодня утром вулкан снова проявил активность...</p>
  <time datetime="2026-11-04">4 ноября 2026</time>
</article>

🧩 <section> — тематический раздел

Это часть страницы, объединённая одной темой. Обычно у него есть свой заголовок.

Примеры: глава книги, вкладка в интерфейсе, раздел «Новости», раздел «Контакты».

<section>
  <h2>Наши курсы</h2>
  <p>Мы обучаем HTML, CSS и JavaScript...</p>
</section>
🤔
В чём разница между <article> и <section>?
Задай себе вопрос: «Можно ли этот блок вырвать из страницы и он будет понятен сам по себе?»
✅ Да → используй <article> (новость, пост, товар)
❌ Нет, это просто часть страницы → используй <section>

Например: «Блок с тремя последними новостями» — это <section>, а каждая новость внутри — это <article>.

📬 <address> — контактная информация

Этот тег используется для указания контактов автора страницы или статьи. Внутри него обычно пишут email, телефон, физический адрес. 

<address>
  Связаться с нами:<br>
  <a href="mailto:info@it-kamchatka.ru">info@it-kamchatka.ru</a><br>
  г. Петропавловск-Камчатский, ул. Ленинская, 12
</address>

🎬 Мультимедиа: <video> и <audio>

HTML5 позволяет встраивать видео и аудио без Flash и сторонних плагинов. Это тоже семантические теги — они говорят браузеру: «Здесь медиа-контент».

🎥 Видео

<video src="volcano.mp4" controls width="640">
  Ваш браузер не поддерживает видео.
</video>
  • controls — показать кнопки управления (play, pause, громкость).
  • autoplay — запускать автоматически (но браузеры часто это блокируют).
  • loop — зациклить воспроизведение.
  • muted — начать без звука.
  • poster="preview.jpg" — картинка-превью до запуска.

🎵 Аудио

<audio src="sound.mp3" controls>
  Ваш браузер не поддерживает аудио.
</audio>

Атрибуты те же самые: controls, autoplay, loop, muted.

📼 Несколько форматов на случай чего

Разные браузеры поддерживают разные форматы. Чтобы твой файл точно воспроизвёлся везде, можно указать несколько источников через тег <source>: 

<video controls width="640">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  Ваш браузер не поддерживает видео.
</video>

🗺️ Итоговая схема страницы

А теперь давай соберём всё вместе и посмотрим, как выглядит профессиональная структура:

HTML Скелет современного сайта 
<body>
  <header>
    <h1>IT-куб Камчатка</h1>
    <nav>
      <ul>
        <li><a href="/">Главная</a></li>
        <li><a href="/courses">Курсы</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <section>
      <h2>Последние новости</h2>
      <article>...новость 1...</article>
      <article>...новость 2...</article>
    </section>
  </main>

  <aside>
    <h3>Реклама</h3>
  </aside>

  <footer>
    <address>Контакты...</address>
    <p>© 2026 IT-куб</p>
  </footer>
</body>
💡
Помни: Семантические теги не заменяют <div>. Они работают вместе. <div> используй для чисто визуальных обёрток (например, чтобы применить CSS-стиль к группе элементов), а семантические теги — когда хочешь передать смысл.

🚀 Практическое задание: «Макет сайта IT-куба»

Создай файл layout.html и сделай семантически правильный макет главной страницы IT-куба Камчатка:

  1. В <header> размести логотип (можно текстом <h1>) и меню <nav> с 4 ссылками (Главная, HTML, CSS, JavaScript).
  2. В <main> создай два <section>: «О нас» и «Наши курсы».
  3. Внутри раздела «Наши курсы» размести минимум 3 <article> — по одному на каждый курс (HTML, CSS, JavaScript). В каждом
    должен быть заголовок <h3> и короткое описание.
  4. Создай <aside> с блоком «Полезные ссылки» (3-4 ссылки на ресурсы для программистов).
  5. В <footer> размести <address> с контактами IT-куба и копирайт.
  6. Добавь в один из <article> видео <video> с камчатским вулканом (можно взять любую ссылку на mp4 из интернета) с атрибутом controls.
  7. Открой файл в браузере. Визуально это будет просто текст, но структура — как у настоящего профессионального сайта! 🏆
