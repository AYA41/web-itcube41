Урок 15

Загрузка файлов, списки и многострочный текст

В прошлых уроках мы научились вводить короткие данные. Но что, если нужно загрузить фотографию, выбрать страну из списка или написать целое письмо? Для этого в HTML есть три специальных инструмента.

📎 Загрузка файлов: type="file"

Поле <input type="file"> открывает стандартное окно выбора файла на компьютере пользователя. Это как почтовый ящик, в который можно «положить» любой файл и отправить на сайт.

HTML Простая загрузка файла 
<label for="photo">Загрузи своё фото:</label>
<input type="file" id="photo" name="photo">

🎯 Атрибут accept — фильтр по типам

Чтобы пользователь не загрузил случайно видео вместо картинки, можно указать, какие типы файлов разрешены. Окно выбора сразу покажет только подходящие файлы. 

<!-- Только картинки -->
<input type="file" accept="image/*">

<!-- Только PDF-документы -->
<input type="file" accept=".pdf">

<!-- Картинки или видео -->
<input type="file" accept="image/*,video/*">

📚 Атрибут multiple — несколько файлов сразу

Добавь это слово, и пользователь сможет выбрать сразу много файлов (с зажатым Ctrl или Shift).

<input type="file" name="gallery" multiple>
⚠️
КРИТИЧЕСКИ ВАЖНО: Чтобы форма с файлом вообще работала, у тега <form> обязательно должен быть атрибут enctype="multipart/form-data". Без него файлы не отправятся!

<form action="#" method="post" enctype="multipart/form-data">

📋 Выпадающий список: <select> и <option>

Если вариантов выбора много (например, 80 стран или 12 месяцев), делать для каждого отдельный переключатель — неудобно. Лучше использовать выпадающий список <select>. 

<label for="month">Месяц путешествия:</label>
<select id="month" name="month">
  <option value="">-- Выбери месяц --</option>
  <option value="july">Июль</option>
  <option value="august" selected>Август</option>
  <option value="september">Сентябрь</option>
</select>
💡
Атрибут selected работает как checked у чекбоксов — он делает вариант выбранным по умолчанию. А первый пустой <option> — это хорошая практика, чтобы пользователь осознанно сделал выбор, а не отправил форму со случайным вариантом.

📂 Группировка вариантов: <optgroup>

Если вариантов очень много, их можно объединить в группы с заголовками:

<select name="place">
  <optgroup label="Вулканы">
    <option>Ключевская Сопка</option>
    <option>Авачинская Сопка</option>
  </optgroup>
  <optgroup label="Озёра">
    <option>Курильское озеро</option>
    <option>Озеро Тао-Тучек</option>
  </optgroup>
</select>

📝 Большое поле текста: <textarea>

Тег <input type="text"> удобен для коротких данных (имя, email). Но что, если нужно написать целое сообщение, отзыв или историю? Для этого существует <textarea> — многострочное текстовое поле. 

<label for="message">Расскажи о себе:</label>
<textarea id="message" name="message" rows="5" cols="40" placeholder="Напиши здесь..."></textarea>
  • rows — высота поля в строках.
  • cols — ширина поля в символах.
  • Важно: <textarea> — парный тег! Между <textarea> и </textarea> не должно быть ничего, даже пробела. Иначе этот пробел появится в поле.
⚠️
Частая ошибка:
❌ <textarea placeholder="Текст">Подсказка внутри</textarea> — слово «Подсказка внутри» станет значением по умолчанию!
✅ <textarea placeholder="Текст"></textarea> — правильно, подсказка отображается серым.

🔍 Сравним три элемента

Элемент Для чего Особенность
type="file" Загрузка файлов Нужен enctype у формы
<select> Выбор из готового списка Экономит место на странице
<textarea> Длинный текст Парный тег, можно переносить строки

  2. Добавь поле type="file" с атрибутом accept="image/*" и multiple, чтобы можно было загрузить сразу несколько фотографий.

  5. Внизу — кнопка «Отправить работу».
  6. Открой файл в браузере и проверь, что все элементы работают корректно!
