Урок 01

Что такое HTML и как он работает?

HTML (HyperText Markup Language) — это язык разметки. Если представить сайт как дом, то HTML — это его фундамент, стены и крыша. Он говорит браузеру: «Здесь будет заголовок, здесь картинка, а здесь кнопка».

🧱 Что такое тег?

HTML состоит из тегов. Тег — это специальная команда, спрятанная в угловых скобках < >. Большинство тегов парные, как две половинки бутерброда: есть открывающий тег и закрывающий (с косой чертой /).

HTML Пример парного тега 
<p>Привет, Камчатка! Я учусь кодить.</p>
🥪
Аналогия с бутербродом:
<p> — это нижний кусок хлеба (открытие).
Текст — это начинка.
</p> — это верхний кусок хлеба (закрытие).

Некоторые теги одиночные (им не нужно ничего закрывать), например, перенос строки <br> или картинка <img>.

🏠 Скелет любой HTML-страницы

Каждая страница в интернете начинается с одинаковой базовой структуры. Вот как она выглядит:

HTML Базовый шаблон 
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Мой первый сайт</title>
  </head>
  <body>
    <h1>Привет, мир!</h1>
    <p>Это мой самый первый текст на сайте.</p>
  </body>
</html>

🧩 Разбираем по частям:

  • <!DOCTYPE html> — «Паспорт» документа. Говорит браузеру: «Я современный HTML5, отображай меня правильно!»
  • <html> — Главная «коробка», внутри которой лежит весь сайт.
  • <head> — «Мозг» сайта. Здесь хранятся настройки, кодировка и название вкладки (<title>). Этого не видно на самой странице!
  • <body> — «Тело» сайта. Здесь находится всё, что пользователь видит на экране: тексты, картинки, кнопки.

⚙️ Что такое атрибуты?

Тегам можно давать дополнительные настройки. Они пишутся внутри открывающего тега и называются атрибутами. Атрибут всегда состоит из имени и значения в кавычках: имя="значение". 

<!-- Атрибут href указывает, куда ведёт ссылка -->
<a href="https://it-kamchatka.ru">Сайт IT-куба</a>

<!-- Атрибут src указывает путь к картинке -->
<img src="volcano.jpg" alt="Вулкан">

🚀 Твоё первое задание

Давай создадим твою первую веб-страницу прямо сейчас!

  1. Создай на рабочем столе папку my-site.
  2. Открой «Блокнот» (или OpenIDE, если он есть).
  3. Скопируй туда код из блока «Базовый шаблон» выше.
  4. Замени текст внутри <h1> на своё имя, а в <p> напиши, почему ты хочешь учиться программировать.
  5. Нажми «Файл» → «Сохранить как...». Назови файл index.html (важно, чтобы в конце было именно .html, а не .txt!).
  6. Дважды кликни по файлу index.html. Он откроется в браузере. Поздравляю, ты создал свой первый сайт! 🎉
